- **Backend** — TypeScript/NestJS, Java/Spring Boot, Python/FastAPI, PostgreSQL, Redis

- **Infra** — AWS(EKS·EC2·S3), Docker, Kubernetes, Jenkins, GitHub Actions, Cloudflare Tunnel
