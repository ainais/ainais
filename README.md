## 이정성 · Lee JeongSeong

백엔드에서 출발해 웹·앱·인프라까지 혼자 끝까지 만드는 풀스택 개발자입니다.
현재 B2B 자동차 부품 유통 플랫폼에서 NestJS·React 서비스와 LLM 기반 업무 자동화를 개발하고 운영하고 있습니다.

- 블로그: [ainais.tistory.com](https://ainais.tistory.com/)
- 위치: Seongnam, Korea

### 사이드 프로젝트

업무와 별개로 혼자 만드는 개인 프로젝트입니다.

- [**boxing-commerce**](https://github.com/ainais/boxing-commerce) (진행 중) — 복싱용품 가격 비교 서비스. 웹 프로토타입과 상품 조회 API 개발 중 · Spring Boot · Next.js · PostgreSQL
- [**routineq**](https://github.com/ainais/routineq) (진행 예정) — 프롬프트로 매일 공부 문제를 만들어 주는 루틴 앱. 이전 버전에서 Google Play 내부 테스트까지 진행했고 모노레포로 재개발 예정 · NestJS · React · React Native
- [**url-shortener**](https://github.com/ainais/url-shortener) — Spring Boot · Redis 기반 URL 단축 서비스

### 기술 스택

- **Backend** — TypeScript/NestJS, Java/Spring Boot, Python/FastAPI, PostgreSQL, Redis
- **Frontend · App** — React, React Native(Expo), Flutter
- **AI** — LangChain, RAG, ReAct Agent, OpenAI API, YOLO
- **Infra** — AWS(EKS·EC2·S3), Docker, Kubernetes, Jenkins, GitHub Actions, Cloudflare Tunnel

### 일하는 방식

- 현업이 실제로 쓰는 흐름을 먼저 확인하고 화면·API로 옮깁니다.
- 자동화는 잘못 돌아갈 때 비용이 크므로 재시도·제한·멈출 지점을 먼저 설계합니다.
- 설계 근거와 의존 관계는 문서로 남깁니다.
